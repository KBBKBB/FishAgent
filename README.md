# FishAgent（垂钓智行）

> 为钓鱼爱好者提供**鱼情分析**与**钓位推荐**的 AI 智能体。
> 归属：KBB OPC ｜ 定位：**钓鱼辅助决策工具**（给「参考建议」，不承诺渔获）。

## 这个项目要解决什么

钓鱼佬的两大痛点：

1. **不知道今天适不适合钓鱼** —— 鱼口受气压、温度、风力、降水影响，普通人看不懂气象数据。
2. **不知道去哪里钓** —— 即便想起竿，也缺乏对附近水域、钓位质量的有效判断。

**核心缺口**：数据到处都是，但**没有人替用户做出「去不去、去哪、几点去」的决策**。

差异化主张（详见 `Spec/Mission.md`）：决策前置而非数据前置、把「能去」和「值得去」合并、可解释、**敢劝退**。

## 关键实现红线（不可协商）

| 编号 | 红线 |
|---|---|
| R1 | 坐标系统一：WGS84 → GCJ-02，唯一入口，禁止裸坐标进地图 API |
| R2 | 周边搜索半径硬校验：≤ 50000 米（超限静默降级为 3000 米且不报错） |
| R3 | 高德 Key 严禁下发客户端（服务端中转 + IP 白名单 + `sig`） |
| R4 | 车程口径：终点用 `entr_location`；往返分别计算 ≤7200s，不得单程×2 |
| R5 | 禁钓过滤前置（高危类型必须权威矢量边界，边界不明保守排除） |
| R6–R8 | AI 内容标识 / 位置隐私「用完即弃」/ 不播报气象预报 |
