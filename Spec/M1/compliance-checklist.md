**风险等级：极高。失败需改 H5 / App，影响面大。**

|---|---|

| 判定 | **权限开通成功** = 通过；失败则载体改为 H5/App（须提前启动） |
| 依据 | 立项文档 4.4 / 9.2 之 A7；TechStack §3 载体风险 |
| 动作 | 提交主体资质与隐私接口申请；同步准备 H5/App 备选方案 |
| 状态 | `[ ]` 待办 |

> **注意**：`wx.getLocation` 属需申请开通的隐私接口，**并非「装上就能拿定位」**。
