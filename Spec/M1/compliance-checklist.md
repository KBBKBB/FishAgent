## T09 🔴 小程序定位权限可行性确认（对应假设 A7）

**风险等级：极高 → 经 M1 核实后调整为「高，但有明确降级路径」。**

> **M1 结论（详见 `miniprogram-location-permission.md`）**：`wx.getLocation` 自 2022-04-18 起实行
> **准入开通 + 类目限制**。支持的类目集中在交通/餐饮/汽车/电商/金融；「工具-信息查询」**仅限打卡类场景**。
> **「钓鱼工具 + 附近水域推荐」不在已列举的支持场景内 → 很可能被拒（61036 类目不符）。**

| 项 | 内容 |
|---|---|
| 待确认 | 主体资质与**服务类目**是否满足 `wx.getLocation` 申请条件 |
| 判定 | 权限开通成功 = 通过；被拒则走降级方案 |
| 依据 | 立项文档 4.4 / 9.2 之 A7；TechStack §3 载体风险 |
| **降级方案** | **小程序「地图选点 + 行政区选择」（`<map>` + marker，绕开隐私接口）→ 不依赖定位权限即可上线**；H5/App 为备选 |
| 状态 | `[~]` 规则已核实；申请与产品侧确认待办 |

> **注意**：`wx.getLocation` 属需申请开通的隐私接口，**并非「装上就能拿定位」**；
> 且必须配置《用户隐私保护指引》并在 `requiredPrivateInfos` 中声明，否则**无法提交代码审核**。
>
> **对项目的意义**：采用「地图选点」后，**A7 由「可阻塞项目」降为「体验优化项」**，无须改 H5/App。

## T10 🔴 生成式 AI 备案路径咨询

**风险等级：高。工期可能很长。**

> **M1 结论（详见 `ai-filing-compliance.md`）**：本项目属「**仅调用第三方已备案大模型 API + 应用层封装**」，
> 走**轻通道**：**大模型登记（省级网信办，约 15~45 工作日 / 3~4 个月）+ 算法备案（生成合成类）**，
> **无需**自研「大模型备案」（4~8 个月）。**接入已备案模型 ≠ 免责，仍须独立登记。**
> **风险由「🔴 未知工期」降为「🟡 路径明确、工期可控」。**

| 项 | 内容 |
|---|---|
| 待确认 | 面向境内公众提供生成式 AI 服务的**登记 / 算法备案**要求、工期预估 |
| 关键认知 | **接入已备案大模型 ≠ 免责**——调用第三方已备案模型 API，仍作为服务提供者担责，须**独立登记** |
| 路径判定 | **登记 + 算法备案**；判定硬标准 =「**是否改动模型权重 / 是否预训练·微调**」 |
| 前置红线 | 主体须为**独立法人企业**（KBB OPC ✅，个人/个体工商户不可办理）；**服务器必须境内** |
| 灰区（待书面确认） | ① 纯「钓鱼工具类」是否构成「舆论属性/社会动员能力」（是否需要算法备案）；② 我们的规则引擎二次加工是否被认定为「实质性修改」而升级为**备案** |
| 依据 | 《生成式人工智能服务管理暂行办法》《人工智能生成合成内容标识办法》《互联网信息服务算法推荐管理规定》；立项文档 7.4 |
| 动作 | **M1 即启动属地网信办咨询**；**M2 内测前完成登记**；**M3 上线前完成算法备案 + 落实标识/公示编号** |
| 状态 | `[~]` 规则与路径已核实；属地口径咨询与材料筹备待办 |

## T11 🔴 高德条款对 POI 缓存 / 持久化的限制

**风险等级：高。「护城河」合法性的地基。**

> **M1 结论（详见 `amap-terms-caching.md`）**：高德《开放平台服务协议》（2025-12-03 版）**默认禁止**
> 对服务数据「存储/缓存/下载/复制」（§3.5、§4.12.3），并**明令禁止「二次包装、制作衍生品、汇编」**（**§7.3**）。
> 因此**「基于高德数据沉淀 UGC 钓点库」属需「事先书面同意」的行为**；且商业目的须购买**技术服务许可**（§3.2）。
> **默认设计会违约，必须在 M2 落库前解决。**

| 项 | 内容 |
|---|---|
| 待确认 | POI 结果可否缓存、可否持久化入库、可否与 UGC 数据混合存储 |
| **判定（条款对照）** | 🔴 **默认不可缓存/落库**（§3.5/§4.12.3/§7.3）；衍生数据库/混存须**事先书面同意**（§7.3）；商业用途须**技术服务许可**（§3.2） |
| 依据 | 高德《开放平台服务协议》§3.2/§3.5/§4.12/§7.3/§7.4/§12.2（2025-12-03）；立项文档 7.7；TechStack D6 |
| **产品级对策** | **A 实时召回不落库（推荐基线）**；B 双源解耦；C UGC 独立建库（字段隔离）；D 与高德签商务授权 |
| 动作 | 法务对照协议出**书面结论**；商务提交工单（§3.5）+ 询价技术服务许可（§3.2） |
| 状态 | `[~]` 条款已对照、风险已定性；法务书面结论与商务对接待办 |
