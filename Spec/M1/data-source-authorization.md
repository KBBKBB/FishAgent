# M1-T12 《数据源授权清单 v1》

> 对应 Roadmap §2.2 M1-T12 与立项文档 7.6「数据授权链路穿透」。
> 状态：`[~]` 初版（登记框架与已知结论）；商用结论需 M1 法务复核后定稿。

## 1. 为什么需要「三级授权链路」

Open-Meteo 的数据来自各国气象机构（含 CMA），**上游机构的许可约束会穿透传导至本项目**。
仅登记「Open-Meteo 一层」不足，须逐层确认商用许可、再分发许可与署名要求：

```
上游机构 (CMA / NOAA / ECMWF …)
        │  许可约束穿透
        ▼
数据聚合方 (Open-Meteo / 和风 / 心知)
        │  免费层多为 Non-Commercial
        ▼
本项目 (FishAgent)
```
