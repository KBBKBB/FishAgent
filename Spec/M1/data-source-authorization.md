## 1. 为什么需要「三级授权链路」

Open-Meteo 的数据来自各国气象机构（含 CMA），**上游机构的许可约束会穿透传导至本项目**。
仅登记「Open-Meteo 一层」不足，须逐层确认商用许可、再分发许可与署名要求：

```
上游机构 (CMA / ECMWF / DWD / NOAA …)
        │  许可约束穿透（Open-Meteo 统一以 CC BY 4.0 再分发）
        ▼
数据聚合方 (Open-Meteo / 和风 / 心知)
        │  免费 API 层多为 Non-Commercial
        ▼
本项目 (FishAgent)
```

### 2.1 气象 / 气压

| 层级 | 主体 | 许可证 / 条款 | 商用结论 | 署名方式 | 状态 |
|---|---|---|---|---|---|
| 聚合方 | **Open-Meteo** | 免费层**仅限非商用**（<1 万/日、5 千/时、600/分、30 万/月）；**数据许可 CC BY 4.0**；服务端代码 **AGPLv3** | ❌ 免费层不可商用。商用二选一：① **订阅**（`customer-api.open-meteo.com` + API key）；② **自托管**（AGPLv3 服务端 + 自行获取 CC BY 4.0 开放数据） | **必须署名**（CC BY 4.0） | ✅ 已核实 2026-10-12 |
| 上游 | 各国气象机构（**CMA / ECMWF / DWD / NOAA / Météo-France / JMA / UKMO** 等） | 模型数据多为开放数据，Open-Meteo 统一以 **CC BY 4.0** 再分发 | ✅ CC BY 4.0 **允许商用**（需署名） | 署名 Open-Meteo + 上游模型 | ✅ 已穿透（Open-Meteo 层） |
| 备源 | 和风天气 | 免费版条款 | ⏳ 需确认授权范围 | 按条款 | 待确认 |
| 备源 | 心知天气 | 免费版条款 | ⏳ 需确认授权范围 | 按条款 | 待确认 |
| 备用 | CMA 中国气象数据网 | 需注册、门槛高 | ⏳ | — | 待评估 |

> **关键区分（v2 新增）**：**「数据」与「免费 API 服务」是两套许可**——
> 数据是 **CC BY 4.0（可商用、需署名）**，而**免费 API 服务**限定**非商用**。
> 因此变现前不必只走订阅：**自托管开源服务端（AGPLv3）+ 自取开放数据**亦是合规商用路径（需评估运维成本）。
> **变现前置条件**：任一变现路径启用即构成「商用」，须先完成气象数据商用授权（D7）。
