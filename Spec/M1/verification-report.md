## 二、G1 决策门判定

| 门 | 时点 | Go 条件 | 当前判定 |
|---|---|---|---|
| **G1** | M1 末 | A1 + A2 + A3 + A4 全部通过 | **🟡 趋于 Go**：A2 ✅、A4 ✅、A1 初步达标（80%）、A3 接口可用但**绝对日配额待控制台核对**。正式判定需补齐 **A1 每城 50 点真值集**、**A3 配额绝对数**、**A7 载体权限** |

**No-Go 触发后的动作**（预先约定，避免沉没成本）：
- 若 **A1 < 50%** 或 **A2 一线 < 3 个** → 启动 **Plan B1**（UGC 众包 + 车程排序，M4 提前）；
- 若接口能力不成立（**A4 失败**）且无替代方案 → **终止立项**。

### G1 附加必答项（竞品调研）—— 已具备证据

依据 `competitor-research.md`：

> **证据显示「气压 + 鱼情预测」在垂类 App 中已高使用率且体验良好**
> （钓鱼人 4.0/2840 评；FishWeather 4.7/20000+ 评，且已实现「AI 鱼口预测 + 黄金时段」）。

**按立项文档 1.3.5 / 9.3，G1 建议采纳以下调整（已于 2026-10-10 落地）：**

1. 将「气压 + 鱼情预测」**由主打卖点降级为基线功能**；
2. 资源集中到两个未被竞品明确占据的差异点：
   - **「往返 2 小时车程」的精确可达性筛选**；
   - **「敢劝退」的决策立场**（产品原则 P1）；
3. UGC 钓点保留为 M4 长期护城河，**M2 不与其正面竞争钓点库规模**。

**落地位置**（卖点优先级调整）：

| 文档 | 变更 | 版本 |

| `Spec/Mission.md` | §四 重写为核心差异点 / 次要强化点 / 基线功能三层；§6.1、§8.1、§九 同步 | v1.1 |
| `Spec/TechStack.md` | 新增 §1.1 资源优先级；§4.1 标注基线、§4.2 标注核心投资 | v1.1 |
