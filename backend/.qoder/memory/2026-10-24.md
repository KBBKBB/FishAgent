- 唯一 canonical 入口为裸域，`www` 必须 301 跳转到裸域（人类明确偏好 `www` 时可对调）；会话 Cookie 为 host-only，禁止裸域与 `www` 同时提供应用，避免“登录后回到未登录”。
- 生产环境需 `FISHAGENT_PUBLIC_ACCESS_ENABLED=true`、`FISHAGENT_PILOT_TRUST_PROXY_HEADERS=true`，读取 `CF-Connecting-IP`；必须确认源站不可直连，否则头可伪造。限流必须按真实公网 IP 分桶，不得退化为全部 `127.0.0.1`，该点为 D 组 RD-55 的 P1 阻塞判据。
- Cloudflare 配置：`/`、`/sw.js`、`/manifest.webmanifest` 设 Bypass，避免 PWA 更新滞后；`/`、`/app.js`、`/api/*`、`/pilot/login` 不得启用 Rocket Loader 或 JS challenge，登录 POST 必须直达源站；为 `/api/*`、`/pilot/login` 配置 WAF Skip。
- 超时与故障预期：Cloudflare 源站响应上限约 100 秒，长 Agent 对话须在限内返回或给出明确错误，不能挂起；主机离线预期 502/1033/530，runbook 恢复目标 ≤60 秒；App 壳冷启动首屏 ≤5 秒，数据耗时另按 S1 P95，不混算。
