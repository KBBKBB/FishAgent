## 10. 执行顺序与证据规范

### 10.1 执行顺序（风险优先）

1. **部署后命令行冒烟（真机前，桌面）**：RD-42、RD-43、RD-44、RD-45、RD-46、RD-47、RD-48；用 `curl -I` 与带 Cookie jar 的登录请求完成，节省真机时间。
2. **登录链路**：RD-49 → RD-12..16 → RD-53。
3. **PWA**：RD-01..07 → RD-24..30 → RD-50。
4. **定位与高德**：RD-08..11 → RD-51 → RD-19..23 → RD-52。
5. **限流/IP**：RD-54、RD-55。

### 10.2 证据命名与判定（RD-60）
